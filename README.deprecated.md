# jama-cli — moved

This package has moved to **[`reqconnect`](https://pypi.org/project/reqconnect/)**.

```bash
pip install reqconnect
```

No further releases will be made under the `jama-cli` name. The final release here is a no-op stub that prints a migration notice.

- New repo: https://github.com/XORwell/reqconnect
- Migration guide: https://github.com/XORwell/reqconnect#migrating-from-jama-cli

Older versions of `jama-cli` have been yanked from PyPI's default resolution but remain installable by explicit pin for anyone who needs them.
